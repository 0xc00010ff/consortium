Consortium architecture

Consortium is a group chat of AI models. You write a message, each model at the table answers, and you decide what happens next.

Each exchange is a round. In a round, every agent answers your message at the same time. Any arbiters, which are models with their own instructions, answer after the agents. Then the table waits for you: add a note, have a private word with one agent, or press Next round.

One setting changes how a table works. With Interaction set to Group, the agents read each other. Set to Independent, each agent reads only you.

How a table works

  • Round 1. Your first message goes to every agent. The agents answer at the same time. Then each arbiter answers in turn, reading everything from the round.
  • Group or Independent. In a Group table, agents read the host, the other agents and the arbiters. In an Independent table, each agent reads only you and its own earlier replies. Arbiters read everything either way.
  • Between rounds. Nothing runs until you press Next round. You can add a note or leave it blank.
  • Private conversations. From any reply, you can open a conversation with that one agent and go back and forth. Only that agent remembers it. The other agents do not see it.
  • Arbiters. An arbiter is a model with its own instructions that answers after the agents. Use one to track ideas, summarize, score, or hold the table to a rule. Anything else you want is a matter of what you write.

What changes in the code

The engine gets much smaller. A round is one parallel call to the agents and then one call per arbiter, with nothing to parse. The code that calls models, lists them and saves tables stays as it is.

AreaNowAfter
ModesIndependent, Debate, Consensus, Mission, each with its own steps and stop rulesOne table, with an Interaction setting: Group or Independent.
A roundOpening, turns in rotating order, votes, closingAgents answer at once, then arbiters one after another. Then the table waits for you.
Reply formatA metadata block with positions, votes and drafts, parsed and repairedPlain text. Nothing to parse.
ModeratorA fixed role that checks stop rules and writes a summaryGone. An arbiter with instructions covers it when you want it.
Host inputNotes that land at the next turn, pause and stopA note before each round, and private conversations with any agent.
Side panelPosition chart, draft versions, votesParticipants, or the open private conversation.
KeptThe model route and the browsing tools, the model list, saving to the browser, markdown export, image attachments, and sample mode.

Defaults I would start with

  • Agents answer at the same time within a round. Each agent reads the earlier rounds, your note, and in a Group table the other agents’ earlier replies. Turn-taking can come back later as a setting if a round feels flat.
  • Arbiters read everything, including every agent’s replies in an Independent table, since comparing agents is the point of having one.
  • Agents are called A, B, C and D in what the models read. You see the model names. This keeps the comparison fair, and it needs no setting.
  • Private conversations stay private. Only that agent carries them forward. If you want the table to know, say so in your note.
  • Changing participants or the Interaction setting applies from the next round. Past rounds stay as they were.
  • Light theme by default, following the system setting for dark.
